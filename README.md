# BEL Prep 🎓

**BEL Prep** е уеб платформа в разработка за подготовка по **български език и литература (БЕЛ)** за националното външно оценяване след **7. и 10. клас** и държавния зрелостен изпит след **12. клас**.

Целта е на едно място учениците да намират учебни материали, да упражняват знанията си с тестове и пробни матури и да проследяват напредъка си. Учителите могат да създават съдържание, а администраторите да управляват платформата.

> **Статус:** Проектът е в разработка. Описаните функции са планирани и се реализират поетапно.

## Потребителски роли

| Роля | Планирани функционалности |
| --- | --- |
| **Ученик** | Регистрация и вход; избор на клас; преглед, търсене и филтриране на учебни материали; оценки и коментари; решаване на тестове и примерни матури; история на резултатите и прогрес |
| **Учител** | Регистрация с избор на училище; одобрение от администратор; създаване, редактиране и изтриване на собствени материали и тестове; задаване на въпроси, точки и време; статистика и обратна връзка |
| **Администратор** | Предварително създаден профил (без публична регистрация); одобряване на учители; управление на потребители, училища, материали, тестове и коментари; обща статистика |

## Основни модули

- **Authentication & Authorization:** вход, регистрация, роли, права за достъп, възстановяване на парола.
- **Материали по БЕЛ:** теория, анализи на произведения, граматика, правопис и пунктуация, организирани по клас и категория.
- **Тестове и пробни матури:** създаване от учители, решаване от ученици, времеви ограничения и автоматично оценяване на подходящите типове въпроси.
- **Резултати:** история на решените тестове и визуализация на напредъка.
- **Обратна връзка:** оценки и коментари към материалите.
- **Администрация:** одобряване на учители и модериране на съдържанието.

## Структура на проекта

Разработката е разделена на два отделни GitHub repositories:

- **[BEL-Frontend](https://github.com/Team-Simeon/BEL-Frontend)** — потребителски интерфейс за ученици, учители и администратори.
- **[BEL-Backend](https://github.com/Team-Simeon/BEL-Backend)** — API, бизнес логика, удостоверяване, управление на данни и роли.

Проектът се разработва от **екип от четирима души**. Задачите са описани и разпределени като GitHub Issues в двата repositories.

## Работен процес

1. Избери Issue от съответното repository.
2. Работи в отделен branch за задачата.
3. Добави тестове, когато е приложимо.
4. Създай Pull Request за преглед преди сливане в `main`.

## Лиценз

## Frontend

Frontend частта ще предоставя интерфейси за трите роли и ще комуникира с Backend чрез REST API.

### Планирани технологии

- React + TypeScript
- React Router
- CSS или Tailwind CSS (според избора на екипа)
- HTTP клиент за комуникация с Backend API

### Основни екрани

| Роля | Планирани страници |
| --- | --- |
| Общи | Login, Register, Forgot Password, Profile |
| Ученик | Dashboard, Materials, Material Details, Tests, Mock Exams, Test Solving, Results |
| Учител | Dashboard, My Materials, Material Editor, Test Builder, Results, Feedback |
| Admin | Dashboard, Users, Pending Teachers, Schools, Materials, Tests, Comments |

### UX принципи

- Responsive дизайн за телефон, таблет и компютър.
- Общи компоненти за навигация, форми, грешки и зареждане.
- Достъпен интерфейс и ясно обозначени действия.
- Скриване на недостъпни действия в UI; реалната проверка на правата се извършва от Backend.

### Стартиране

Командите за инсталация и локално стартиране ще бъдат добавени след инициализирането на Frontend проекта. API адресът трябва да бъде конфигурируем чрез environment настройка.
